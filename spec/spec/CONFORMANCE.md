# Conformance

Intent conformance concerns authored Knowledge, including Check definitions.
It requires the declared current schemas, source grammar, metadata resolution and
processing semantics. A conforming reader reports incomplete observations and
unsupported operations explicitly. A complete current Check may describe future
implementation without an adopted implementation scope.

Public result carriers must match their named schemas and preserve the distinction
between source validity, observation completeness and implementation conclusions.
Checks stop at definition; conformance does not require a verifier, executable
binding or operational result store.

The [implementation test map](../../tests/README.md#verification-owners) identifies
source and installed checks. Passing those checks does not establish software
satisfaction of user Checks or human usefulness.
