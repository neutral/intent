# Intent glossary

- **Knowledge.** Software meaning authored in Markdown, with explicit identity, state
  and global metadata, in six kinds.

- **Product Knowledge.** Behavior, Assurance, Blueprint, Description, and Check.

- **Behavior.** A functional outcome and its observable boundaries.

- **Assurance.** An obligation, invariant, operating quality, or failure limit.

- **Blueprint.** An assessable structural decision and its tradeoffs.

- **Description.** Explanation and exact primary ownership of a coherent implementation
  unit.

- **Check.** A falsifiable proposition and the evidence needed to examine it.

- **Discipline.** Independently selectable advisory practice guidance.

- **Identity.** Stable kind-prefixed ID, independent of filename.

- **Lifecycle status.** `draft`, `current`, `superseded` or `retired`, expressing how
  one document should be used now.

- **Occurrence.** An exact observed document and selected global context in a named
  source basis, with generated fingerprints.

- **Record context.** The selected catalog registration, connections and used source
  definitions for one stable record ID.

- **Currentness.** Standing established by a record's explicit authored status.

- **Source basis.** The exact repository observation against which results are
  interpreted.

- **Primary coverage.** Exactly one distinct current Description identity per governed
  artifact.

- **Shadow.** `intent/description/` directories mirroring repository-relative source
  directories.

- **Required evidence.** Material a Check definition says would support its assessment;
  operational collection and reporting belong to the implementation area.

- **Fingerprint.** Full SHA-256 content identity computed by tools, not authored
  bookkeeping.

- **Pack.** Publisher envelope of exact Discipline source, global metadata and a
  generated current-content manifest.

- **Set.** A publisher's convenient grouping of Pack record identities.

- **Registry.** Current target Pack choices, selected practices, expected correspondence and Work Types.

- **Work Type.** Target-local discovery grouping of adopted advisory records.

- **Complete.** Every required stage of the named processing profile finished.

- **Valid.** The complete named profile found no error; not a claim of semantic truth.

- **Intent Editor.** Local interactive reading, navigation, authoring, diagnostics, and
  Check definitions.

- **Intent Portal.** A selected static read-only publication with no local effect
  service.
