# Pack releases the examples adopt

A Pack is released outside any project. The one here is kept beside the
examples so that an example's adoption can be repeated from this repository.

- [js-async/](js-async/): `js-async` 1.0.0, one Discipline, "Errors from the
  store are never swallowed". [reminders](../reminders/README.md) adopts it
  with `intent adopt ../packs/js-async --applies 'src/**'`.
