# Intent examples

The [bounded integer project](../tests/fixtures/bounded-integer/README.md) is a
complete runnable consumer example. Copy it to a disposable directory, install
an explicitly selected Intent archive, and follow its instructions. The project
keeps Knowledge definitions beside independent implementation tests.

The [format fixtures](../spec/examples/manifest.json) supply valid and
invalid conformance cases. They are independently authored test inputs, not a
starter collection or evidence that user Checks have passed.
