# Security

Intent operates on an explicitly selected repository. Reading uses bounded
regular files and reports incomplete observations. A caller supplies and
controls any custom source resolver.

The Editor serves a local loopback interface. Keep its service reachable only
by the intended local user. The MCP adapter communicates over standard input
and output; its host controls process access and repository selection.

Authoring proposals contain exact original and replacement text. Review the
whole proposal and its affected Knowledge, then apply with the same reading
options. Application checks current inputs before writes. Inspect a retained
operation before resuming an interrupted write.

A Portal publishes every byte of each selected Markdown document and its
selected metadata. Review that complete selection for audience suitability
before serving it. The generated files use local assets and inert rendering
of authored links and media. The chosen hosting service controls access.

Send suspected vulnerabilities through the contact route and submission policy in
[CONTRIBUTING.md](CONTRIBUTING.md). Describe the affected version, expected boundary
and observed effect in plain text. Do not send credentials.
